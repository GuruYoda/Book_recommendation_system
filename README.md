# Snake Game

A classic Snake game you can play locally in Chrome.

## How to play

1. Open `index.html` in Chrome (double-click the file, or drag it into a browser tab).
2. Click **Play** or press **Space** to start.
3. Move with **arrow keys** or **WASD**.
4. Press **Space** to pause, **R** to restart.

Your best score is saved in the browser automatically.

## Optional: run a local server

If you prefer serving the files over HTTP:

```powershell
cd C:\Users\gursi\Coding\snake-game
python -m http.server 8080
```

Then open [http://localhost:8080](http://localhost:8080) in Chrome.
